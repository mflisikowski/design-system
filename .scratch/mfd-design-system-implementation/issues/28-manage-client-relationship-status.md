# 28: Manage Client Relationship Status

**What to build:** Let a User mark a Client relationship active or inactive and reverse that decision through contextual Select and Badge behavior that remains independent from Project Status and other Client operations.

**Blocked by:** 25: Qualify and release 0.4.0.

**Status:** ready-for-agent

- [ ] Existing Clients retain the persisted active default and can transition between active and inactive without affecting Projects.
- [ ] Contextual Select behavior covers keyboard, focus, pending, success, failure, and cache reconciliation.
- [ ] Badge mapping communicates relationship status accessibly in all eight contexts without conflating it with Project Status.
- [ ] Direct navigation and refresh retain the confirmed relationship status.
