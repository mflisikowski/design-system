## Unreleased

The foundations, registry distribution proof, executable lint policy, and documentation shell are
being assembled for the first coordinated release.

## Release model

Tokens, lint configuration, and registry metadata share one version. Immutable registry snapshots
remain available after a newer release becomes the latest channel.

## Maturity transitions

Every registry item is explicitly reviewed as planned, experimental, stable, or deprecated.
Transitions appear here with migration guidance when consumer action is required.
