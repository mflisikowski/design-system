## Principles

MFD Design System owns public component APIs, semantic tokens, composition rules, and
accessibility contracts. Components are introduced through validated product flows instead of an
alphabetical catalogue.

## Sources of truth

Code and behavioral tests own runtime behavior. Versioned token files own visual values. Figma
represents approved contracts, while the registry distributes editable React source.

## Start exploring

Begin with [Foundations](/foundations), then inspect the current
[component documentation](/components). Product-level compositions live under
