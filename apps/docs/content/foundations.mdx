## Token architecture

Strict DTCG token files are canonical. Reference tokens hold raw scales, semantic tokens name a
job, and component tokens exist only for documented exceptions. Components consume semantic
roles rather than primitive color values.

## Independent theme axes

Brand, color scheme, and density are independent. Atlas and Bloom each support light and dark
resolved schemes plus comfortable and compact density, producing eight validated contexts.

## Current status

The initial token pipeline, generated CSS, runtime selectors, and contrast checks are in place.
Component-specific foundations are added only when a validated Reference CRM flow requires them.
