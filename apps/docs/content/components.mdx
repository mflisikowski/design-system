## Ownership

MFD owns each public API and accessibility contract. Base UI may supply behavior and shadcn may
distribute source, but neither project defines the MFD component contract.

## Documentation contract

Every component page identifies maturity and introduction version, then documents purpose,
anatomy, public API, states, accessibility, keyboard behavior, content guidance, examples,
installation, and related patterns.

## Available components

- [Registry Sample](/components/registry-sample) — experimental distribution proof for the
  canonical registry pipeline.
- [Button](/components/button) — action variants, density-aware sizes, and loading behavior.
- [Icon and Icon Button](/components/icon) — approved Lucide map and named icon-only actions.
- [Link](/components/link) — semantic inline and standalone navigation.
- [Breadcrumb](/components/breadcrumb) — ordered location hierarchy with an explicit current item.
- [Page Header](/components/page-header) — structural page title, breadcrumb, and actions.
- [Alert](/components/alert) — persistent danger and success feedback.
- [Empty State](/components/empty-state) — compositional absent-content guidance.
- [Table](/components/table) — native table primitives without grid behavior.
- [Field](/components/field) — labels, descriptions, errors, and accessible relationships.

- [Textarea](/components/textarea) — native multiline control with density-aware sizing.
- [Dialog](/components/dialog) — modal composition that becomes full screen below 640px.
- [Alert Dialog](/components/alert-dialog) — consequential confirmation with safe focus and pending protection.
- [Toast](/components/toast) — polite, brief success acknowledgement.
- [Badge](/components/badge) — non-interactive status labels with semantic tones.
- [Select](/components/select) — keyboard-accessible single-value selection with pending behavior.
- [Radio Group](/components/radio-group) — single-value selection with conventional and rich card presentations.
