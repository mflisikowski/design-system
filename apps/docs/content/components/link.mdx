## Anatomy

One native anchor contains consumer-owned text or inline content.

## API

`variant` accepts `inline` or `standalone` and defaults to `inline`. Native anchor properties and refs are forwarded. Use `render` to compose the anchor with an application router such as Next.js Link without losing MFD styling or semantics.

## States

Default, hover, visited browser behavior, and focus-visible are supported. Standalone links reveal an underline on hover and focus.

## Accessibility

Link remains a real anchor, preserving browser navigation, context-menu, and modified-click behavior with a visible focus indicator.

## Keyboard behavior

Tab focuses the Link and Enter follows its destination.

## Figma specification

Anatomy is `Text / optional inline content`. Properties are Variant and content; underline and focus-visible are explicit interaction states.

## Content guidance

Use destination language that remains meaningful outside its surrounding sentence. Do not style actions as links.

## Related patterns

The application shell uses standalone Links for Clients and Settings, with application-owned current-page treatment.
